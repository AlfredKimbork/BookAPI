AUTHENTICATION

API keys

Protected API endpoints require a valid API key.

Generate an API key

API keys can be generated without authentication. Keys generated here have read permission only.

Maximum 100 characters.

Allows creating, updating and deleting resources.

Save this key now.

The API only returns the plaintext key when it is created. It cannot be retrieved afterwards.

Authentication header

Send the key with every protected request using the X-API-Key header.

HTTP
X-API-Key: your-api-key

Permissions

Keys generated by this API are read-only.

Method Permission Generated key
GET Read Allowed
HEAD Read Allowed
OPTIONS Endpoint information Allowed
POST Write Forbidden
PATCH Write Forbidden
DELETE Write Forbidden

Generating a key manually

HTTPie
http POST http://localhost:8888/BookAPI/api/keys \
Content-Type:application/json \
name="My application"
cURL
curl -X POST http://localhost:8888/BookAPI/api/keys \
-H "Content-Type: application/json" \
-d '{"name":"My application"}'

Authentication errors

401 Unauthorized

No API key was supplied, or the supplied key is invalid.

403 Forbidden

The API key is valid, but it does not have permission to perform the requested operation.

Security

Keep your API key private.

API keys should not be committed to source control, shared publicly or included directly in client-side applications.
