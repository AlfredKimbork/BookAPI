AUTHENTICATION

API keys

Requests to the API require a valid API key.

Generate an API key

You can generate a read-only API key directly below. Give your key a name so you can identify it later.

Maximum 100 characters.

Save this key now. Your API key is only returned when it is created. It cannot be retrieved again.

Using your API key

Send your API key using the X-API-Key HTTP header.

HTTPie 
http GET http://localhost:8888/BookAPI/api/books \
X-API-Key:your-api-key
cURL 
curl http://localhost:8888/BookAPI/api/books \
-H "X-API-Key: your-api-key"

Permissions

API keys generated through this documentation are read-only.

Method Permission
GET Allowed
POST Forbidden
PATCH Forbidden
DELETE Forbidden

Authentication errors

401 Unauthorized

The API key is missing or invalid.

X-API-Key: your-key
403 Forbidden

The API key is valid but does not have permission to perform the requested action.
