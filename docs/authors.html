RESOURCE

Authors

Retrieve, create, update and delete authors.

Your key is kept in this browser session only.

GET

/api/authors

Returns a paginated list of authors.

Query parameters

Parameter Type Required Description
page integer No Page number. Defaults to 1.
limit integer No Results per page. Defaults to 10. Maximum 100.
search string No Searches the author's name.

Try it

HTTPie
http GET "http://localhost:8888/BookAPI/api/authors?page=1&limit=10&search=tolkien" \
X-API-Key:your-api-key
cURL
curl "http://localhost:8888/BookAPI/api/authors?page=1&limit=10&search=tolkien" \
-H "X-API-Key: your-api-key"
Response
{
	"data": [
		{
			"id": 1,
			"name": "J.R.R. Tolkien",
			"url": "/api/authors/1"
		}
	],
	"pagination": {
		"page": 1,
		"limit": 10,
		"total": 1,
		"pages": 1
	}
}
HEAD

/api/authors

Performs the same request as GET but returns no response body. Useful for checking whether the endpoint is available.

HTTPie
http HEAD http://localhost:8888/BookAPI/api/authors \
X-API-Key:your-api-key
cURL
curl -I http://localhost:8888/BookAPI/api/authors \
-H "X-API-Key: your-api-key"

POST

/api/authors

Creates a new author. Requires write permission.

HTTPie
http POST http://localhost:8888/BookAPI/api/authors \
X-API-Key:your-api-key 
Content-Type:application/json 
name="J.R.R. Tolkien" 
birth_date="1892-01-03" 
death_date="1973-09-02" 
biography="English writer and academic."
cURL
curl -X POST http://localhost:8888/BookAPI/api/authors \
-H "X-API-Key: your-api-key" 
-H "Content-Type: application/json" 
-d '{
	"name": "J.R.R. Tolkien",
	"birth_date": "1892-01-03",
	"death_date": "1973-09-02",
	"biography": "English writer and academic."
}'

Request body

Field Type Required
name string Yes
birth_date date / null No
death_date date / null No
biography string / null No
JSON
{
	"name": "J.R.R. Tolkien",
	"birth_date": "1892-01-03",
	"death_date": "1973-09-02",
	"biography": "English writer and academic."
}
Generated API keys are read-only, so they cannot use this endpoint.
PATCH

/api/authors/{id}

Partially updates an existing author. Only supplied fields are changed.

HTTPie
http PATCH http://localhost:8888/BookAPI/api/authors/1 \
X-API-Key:your-api-key 
Content-Type:application/json 
biography="An updated biography."
cURL
curl -X PATCH http://localhost:8888/BookAPI/api/authors/1 \
-H "X-API-Key: your-api-key" 
-H "Content-Type: application/json" 
-d '{
	"biography": "An updated biography."
}'
JSON
{
	"biography": "An updated biography."
}
Generated API keys are read-only, so they cannot use this endpoint.
DELETE

/api/authors/{id}

Deletes an author by ID.

HTTPie
http DELETE http://localhost:8888/BookAPI/api/authors/1 \
X-API-Key:your-api-key
cURL
curl -X DELETE http://localhost:8888/BookAPI/api/authors/1 \
-H "X-API-Key: your-api-key"
Response
{
	"message": "Author deleted successfully",
	"deleted_author": {
		"id": 1,
		"name": "J.R.R. Tolkien"
	}
}
Generated API keys are read-only, so they cannot use this endpoint.

Common errors

Status Meaning
400 Invalid request or field.
401 Missing or invalid API key.
403 API key lacks write permission.
404 Author does not exist.
405 HTTP method is not supported.
415 Request is not sent as JSON.
409 Author cannot be deleted while books reference it.
