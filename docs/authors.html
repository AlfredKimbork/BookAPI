RESOURCE

Authors

Create, retrieve, update and delete authors.

GET

/api/authors

Returns all authors.

Query parameters

Parameter Type Description
search string Searches the author's name and biography.
GET

/api/authors/{id}

Returns an author and their books.

Example
GET /api/authors/1
POST

/api/authors

Creates a new author.

JSON
{
    "name": "J.R.R. Tolkien",
    "birth_date": "1892-01-03",
    "death_date": "1973-09-02",
    "biography": "English writer and academic."
}
PATCH

/api/authors/{id}

Updates an existing author.

JSON
{
    "biography": "Updated biography."
}
DELETE

/api/authors/{id}

Deletes an author by ID.
