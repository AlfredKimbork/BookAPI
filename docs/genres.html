RESOURCE

Genres

Retrieve, create, update and delete genres.

Your key is kept in this browser session only.

GET

/api/genres

Returns a paginated list of genres.

Query parameters

Parameter Type Required Description
page integer No Page number. Defaults to 1.
limit integer No Results per page. Defaults to 10. Maximum 100.
search string No Searches the genre name.

Try it

HTTPie
http GET http://localhost:8888/BookAPI/api/genres \
X-API-Key:your-api-key \
page==1 \
limit==10 \
search==fiction
cURL
curl "http://localhost:8888/BookAPI/api/genres?page=1&limit=10&search=fiction" \
-H "X-API-Key: your-api-key"
Response
{
	"data": [
		{
			"id": 1,
			"name": "Science Fiction",
			"description": "Fiction based on scientific ideas."
		}
	],
	"pagination": {
		"page": 1,
		"limit": 10,
		"total": 1,
		"pages": 1
	}
}
HEAD

/api/genres

Performs the same request as GET but returns no response body. Useful for checking whether the endpoint is available.

HTTPie
http HEAD http://localhost:8888/BookAPI/api/genres \
X-API-Key:your-api-key
cURL
curl -I http://localhost:8888/BookAPI/api/genres \
-H "X-API-Key: your-api-key"
GET

/api/genres/{id}

Returns one genre by ID, including the books associated with that genre.

Try it

HTTPie
http GET http://localhost:8888/BookAPI/api/genres/1 \
X-API-Key:your-api-key
cURL
curl http://localhost:8888/BookAPI/api/genres/1 \
-H "X-API-Key: your-api-key"
Response
{
	"id": 1,
	"name": "Science Fiction",
	"description": "Fiction based on scientific ideas.",
	"books": [
		{
			"id": 1,
			"title": "Dune",
			"description": "A science fiction novel.",
			"published_year": 1965,
			"isbn": "9780441172719",
			"pages": 412,
			"cover_url": "https://example.com/dune.jpg",
			"author": {
				"id": 4,
				"name": "Frank Herbert",
				"url": "/api/authors/4"
			},
			"genre": {
				"id": 1,
				"name": "Science Fiction",
				"url": "/api/genres/1"

		}
	]
}
OPTIONS

/api/genres

Returns the HTTP methods supported by this endpoint.

HTTPie

cURL
curl -X OPTIONS -i http://localhost:8888/BookAPI/api/genres
Response headers
HTTP/1.1 204 No Content
Allow: GET, HEAD, POST, OPTIONS
POST

/api/genres

Creates a new genre. Requires write permission.

Request body

Field Type Required
name string Yes
description string / null No
HTTPie
http POST http://localhost:8888/BookAPI/api/genres \
X-API-Key:your-api-key \
Content-Type:application/json \
name="Science Fiction" \
description="Fiction based on scientific ideas."
cURL
curl -X POST http://localhost:8888/BookAPI/api/genres \
-H "X-API-Key: your-api-key" \
-H "Content-Type: application/json" \
-d '{
	"name": "Science Fiction",
	"description": "Fiction based on scientific ideas."
}'
JSON
{
	"name": "Science Fiction",
	"description": "Fiction based on scientific ideas."
}
Generated API keys are read-only, so they cannot use this endpoint.
PATCH

/api/genres/{id}

Partially updates an existing genre. Only supplied fields are changed.

HTTPie
http PATCH http://localhost:8888/BookAPI/api/genres/1 \
X-API-Key:your-api-key \
Content-Type:application/json \
description="An updated description."
cURL
curl -X PATCH http://localhost:8888/BookAPI/api/genres/1 \
-H "X-API-Key: your-api-key" \
-H "Content-Type: application/json" \
-d '{
	"description": "An updated description."
}'
JSON
{
	"description": "An updated description."
}
Generated API keys are read-only, so they cannot use this endpoint.
DELETE

/api/genres/{id}

Deletes a genre by ID.

HTTPie
http DELETE http://localhost:8888/BookAPI/api/genres/1 \
X-API-Key:your-api-key
cURL
curl -X DELETE http://localhost:8888/BookAPI/api/genres/1 \
-H "X-API-Key: your-api-key"
Response
{
	"message": "Genre deleted successfully",
	"deleted_genre": {
		"id": 1,
		"name": "Science Fiction"
	}
}
Generated API keys are read-only, so they cannot use this endpoint.

Common errors

Status Meaning
400 Invalid request or field.
401 Missing or invalid API key.
403 API key lacks write permission.
404 Genre does not exist.
405 HTTP method is not supported.
415 Request is not sent as JSON.
409 Genre cannot be deleted while books reference it.
