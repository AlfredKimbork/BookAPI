RESOURCE

Books

Retrieve, create, update and delete books.

Your key is kept in this browser session only.

GET

/api/books

Returns a paginated list of books.

Query parameters

Parameter Type Required Description
page integer No Page number. Defaults to 1.
limit integer No Results per page. Defaults to 10. Maximum 100.
search string No Searches the title and description.

Try it

HTTPie
http GET "http://localhost:8888/BookAPI/api/books?page=1&limit=10&search=dune" \

X-API-Key:your-api-key
cURL
curl "http://localhost:8888/BookAPI/api/books?page=1&limit=10&search=dune" \
-H "X-API-Key: your-api-key"
Response
{
	"data": [
		{
			"id": 1,
			"title": "Dune",
			"author": "Frank Herbert"
			"genre": "Science Fiction"
			"cover_url": "https://example.com/dune.jpg",
			"url": "/api/books/1"
		}
	],
	"pagination": {
		"page": 1,
		"limit": 10,
		"total": 1,
		"pages": 1
	}
}
HEAD

/api/books

Performs the same request as GET but returns no response body. Useful for checking whether the endpoint is available.

HTTPie
http HEAD http://localhost:8888/BookAPI/api/books \
X-API-Key:your-api-key
cURL
curl -I http://localhost:8888/BookAPI/api/books \
-H "X-API-Key: your-api-key"

HTTPie

X-API-Key:your-api-key
cURL
curl http://localhost:8888/BookAPI/api/books/1 \
-H "X-API-Key: your-api-key"

POST

/api/books

Creates a new book. Requires write permission.

HTTPie
http POST http://localhost:8888/BookAPI/api/books \
X-API-Key:your-api-key 
Content-Type:application/json 
title="Dune" 
description="A science fiction novel." 
published_year:=1965 
isbn="9780441172719" 
pages:=412 
cover_url="https://example.com/dune.jpg" 
author_id:=4 
genre_id:=1
cURL
curl -X POST http://localhost:8888/BookAPI/api/books \
-H "X-API-Key: your-api-key" 
-H "Content-Type: application/json" 
-d '{
"title": "Dune",
"description": "A science fiction novel.",
"published_year": 1965,
"isbn": "9780441172719",
"pages": 412,
"cover_url": "https://example.com/dune.jpg",
"author_id": 4,
"genre_id": 1
}'

Request body

Field Type Required
title string Yes
description string Yes
published_year integer Yes
isbn string Yes
pages integer Yes
cover_url string / null No
author_id integer Yes
genre_id integer Yes
JSON
{
	"title": "Dune",
	"description": "A science fiction novel.",
	"published_year": 1965,
	"isbn": "9780441172719",
	"pages": 412,
	"cover_url": "https://example.com/dune.jpg",
	"author_id": 4,
	"genre_id": 1
}
Generated API keys are read-only, so they cannot use this endpoint.
PATCH

/api/books/{id}

Partially updates an existing book. Only supplied fields are changed.

HTTPie
http PATCH http://localhost:8888/BookAPI/api/books/1 \
X-API-Key:your-api-key 
Content-Type:application/json 
pages:=420 
description="An updated description."
cURL
curl -X PATCH http://localhost:8888/BookAPI/api/books/1 \
-H "X-API-Key: your-api-key" 
-H "Content-Type: application/json" 
-d '{
"pages": 420,
"description": "An updated description."
}'
JSON
{
	"pages": 420,
	"description": "An updated description."
}
DELETE

/api/books/{id}

Deletes a book by its ID.

HTTPie
http DELETE http://localhost:8888/BookAPI/api/books/1 \
X-API-Key:your-api-key
cURL
curl -X DELETE http://localhost:8888/BookAPI/api/books/1 \
-H "X-API-Key: your-api-key"
Response
{
	"message": "Book deleted successfully",
	"deleted_book": {
		"id": 1,
		"title": "Dune"
	}
}

Common errors

Status Meaning
400 Invalid request or field.
401 Missing or invalid API key.
403 API key lacks write permission.
404 Book does not exist.
405 HTTP method is not supported.
415 Request is not sent as JSON.
409 ISBN already exists.
