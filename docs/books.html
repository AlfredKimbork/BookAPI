RESOURCE

Books

Create, retrieve, update and delete books.

GET

/api/books

Returns a paginated list of books.

Query parameters

Parameter Type Description
page integer Page number. Defaults to 1.
limit integer Results per page. Defaults to 10. Maximum 100.
search string Searches the title and description.
Example
GET /api/books?page=1&limit=10&search=dune
GET

/api/books/{id}

Returns a single book by its ID.

Example
GET /api/books/1
POST

/api/books

Creates a new book.

JSON
{
    "title": "Dune",
    "description": "A science fiction novel.",
    "published_year": 1965,
    "isbn": "9780441172719",
    "pages": 412,
    "cover_url": "https://example.com/dune.jpg",
    "author_id": 4,
    "genre_id": 1
}
PATCH

/api/books/{id}

Updates an existing book. Only the fields included in the request are changed.

JSON
{
    "pages": 420
}
DELETE

/api/books/{id}

Deletes a book by its ID.

Example
DELETE /api/books/1
